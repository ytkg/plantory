# Mini Scales carrier

Unit Mini Scales（U177）の上に載せるだけで使える、苔玉の皿用キャリアです。ねじ、接着剤、センサー本体の加工は必要ありません。裏側の浅い位置決め用くぼみとガイドがMini Scalesを囲み、皿を含むキャリアの横ずれを防ぎます。

## 設計値

| 項目 | 値 |
| --- | ---: |
| 皿の高台外径 | 81mm |
| 皿の高台高さ | 2mm |
| キャリア外径 | 87mm |
| 高台用くぼみ内径 | 83mm |
| くぼみ周囲のフチ幅 | 2mm |
| くぼみ深さ | 2mm |
| キャリア厚 | 4mm |
| Mini Scales用の位置決め内寸 | 24.4 × 40.4mm |
| Mini Scales用くぼみ深さ | 0.6mm |
| 位置決めガイド | 中央向きの5mm L字ガイド × 4 |
| ガイド・外周スカートの厚さ | 1mm |
| 外周スカートの下がり | 16.9mm |
| スカート下端とMini Scales底面の隙間 | 0.5mm |

高台の周囲には1mmの余裕を持たせています。高台の高さと同じ2mmのくぼみに完全に収まるため、皿の位置をできるだけ低くできます。荷重は高台からMini Scalesへ伝わります。裏側には、公式組立図の24 × 40mmに合わせた、0.6mm深さの受けを設けました。Mini Scalesの上面全体がこの受けの平らな床に触れて荷重を伝えます。中央の接触パッドはありません。各角の外側にある5mmのL字ガイドは、腕を中央へ向けてMini Scalesの辺に沿わせ、各辺0.2mmの干渉で横ずれを防ぎます。辺の中央はすべて開いているため、Groveケーブルは内側で遮られません。キャリア外周からはMini Scales全体を隠すスカートを下ろし、壁が机に触れて荷重を逃がさないよう、Mini Scales底面より0.5mm上で止めています。ケーブル用には、外周からMini Scales側まで途切れずにつながる直径10mmの丸穴を設けています。

## 印刷

`mini-scales-carrier.scad`をOpenSCADで開き、STLとして書き出します。皿用のくぼみを上にして印刷し、裏側の位置決めガイドの下にサポートを有効にしてください。Groveケーブルは位置決めガイドの中央にある切り欠きから出します。

PLAでも試作できますが、長く水まわりで使う場合はPETGが扱いやすいです。印刷後にMini Scalesへ載せ、苔玉と皿を載せた状態でWeight ATOM S3の画面をシングルタップしてゼロ調整します。

## 調整

別の皿へ替えるときは、OpenSCADファイル先頭の以下を変更します。

- `dish_foot_diameter`
- `dish_foot_height`
- `pocket_clearance`
